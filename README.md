# Cake Stock PWA — ต้นแบบบันทึกรอบซื้อ

## ติดตั้งบน iPhone (หลังนำขึ้นเว็บ HTTPS)
1. เปิด URL ของเว็บนี้ใน Safari
2. แตะปุ่ม Share (แชร์)
3. เลือก **Add to Home Screen (เพิ่มไปยังหน้าจอโฮม)**
4. เปิดไอคอน “บันทึกรอบซื้อ” จากหน้า Home Screen

## ไฟล์
- `index.html` — หน้าจอบันทึกรอบซื้อ (ต้นแบบเดิม ปรับ iOS-style และเพิ่ม PWA hooks)
- `manifest.webmanifest` — ชื่อ/ไอคอน/โหมดเปิดแอป
- `sw.js` — cache app shell แบบพื้นฐาน
- `icons/` — ไอคอน PWA

## ข้อจำกัดตอนนี้
- ต้องนำไฟล์ไปโฮสต์บน HTTPS ก่อนติดตั้งบน iPhone ได้ตามปกติ
- ยังไม่มี backend / ฐานข้อมูลสินค้ากลาง / sync ไปกรุงเทพฯ
- การสแกนกล้องยังขึ้นกับ browser/API และต้องทดสอบบน iPhone จริง
- บันทึกร่างเดิมใช้ localStorage ใน browser ของเครื่องนั้น
- Service worker ช่วย cache หน้าแอป แต่ไม่ได้ทำให้การส่งข้อมูลหรือแนบไฟล์ทุกกรณีทำงานออฟไลน์ได้
