# Cake Stock PWA — บันทึกรอบซื้อและ Product DB

## ใช้งานบน iPhone

1. เปิดเว็บผ่าน HTTPS ใน Safari แล้วกด Share → Add to Home Screen
2. เปิดแอปแล้วกรอกรหัสทีมให้ถูกต้องก่อนเข้าใช้งาน
3. ใช้เมนู “สแกน / จัดการสินค้า” เพื่อเพิ่มหรือค้นหาสินค้า และเมนู “บันทึกรอบซื้อ” เพื่อบันทึกรอบซื้อ
4. อนุญาตกล้องหลังเมื่อเปิดสแกนบาร์โค้ด
5. ฉบับร่างรอบซื้อและรูปใบเสร็จยังเก็บในเบราว์เซอร์ของเครื่องนั้น กด “ส่งออกชุดข้อมูล” เพื่อย้ายหรือส่งต่อ

## Product DB ที่แชร์กัน

- รายการสินค้าเก็บใน `products.json` บน GitHub และอ่านได้สาธารณะ
- เก็บเฉพาะ barcode, ชื่อสินค้า, แบรนด์, ขนาดแพ็ก, หน่วย และหมวดหมู่ ห้ามใส่ราคา ต้นทุน สต็อก หรือข้อมูลส่วนบุคคล
- แอปตรวจรหัสทีมผ่าน Cloudflare Worker ก่อนแสดงเมนู; เพิ่มและแก้ไขสินค้าใช้รหัสเดียวกัน
- ไม่มีปุ่มลบสินค้าในแอป และ Worker ปฏิเสธคำสั่งลบโดยตรง เพื่อป้องกันข้อมูลกลางหาย
- หน้าสินค้าไม่แสดงปุ่มนำเข้า/ส่งออก JSON หรือ Worker URL; การเชื่อมฐานกลางและโหลดข้อมูลทำงานอัตโนมัติ
- GitHub token อยู่ใน Worker secret ไม่อยู่ในเว็บ
- ข้อมูลเก่าที่อยู่เฉพาะในเครื่องต้องเชื่อม Worker แล้วเลือกส่งขึ้นฐานกลาง; ถ้า barcode ซ้ำจะเก็บรายการบนฐานกลางไว้และสำรองรายการในเครื่อง

## ไฟล์หลัก

- `index.html` — แอปบันทึกรอบซื้อ, เครื่องสแกน และ Product DB
- `products.json` — ฐานข้อมูลสินค้าสาธารณะ
- `worker/` — API สำหรับอ่าน/เขียน Product DB
- `sw.js` — cache app shell สำหรับ PWA
- `manifest.webmanifest`, `icons/` — metadata และไอคอน PWA

## ค่าใช้จ่าย

แนวทางนี้ตั้งใจใช้แผนฟรี: GitHub Pages สำหรับ repository สาธารณะ และ Cloudflare Workers Free บนโดเมน `workers.dev` โดยไม่ใช้ฐานข้อมูลหรือบริการเสริมที่ต้องจ่ายเงิน แผน Workers Free จำกัด 100,000 คำขอต่อวัน; หากเกิน โควตาจะปฏิเสธคำขอจนกว่าจะรีเซ็ต ให้คงบัญชีไว้ที่ Free และอย่าอัปเกรดเป็น Workers Paid

## ข้อจำกัด

- ต้องตั้งค่าและ deploy Worker ก่อนการอ่าน/เขียน Product DB ร่วมกันจะทำงาน
- หน้าเข้าสู่ระบบเป็นการกั้นเมนูในเว็บเท่านั้น; `products.json` ยังอ่านได้สาธารณะโดยตรงตามการตั้งค่าปัจจุบัน
- ทุกคนที่มีรหัสทีมเข้าใช้เมนูและเขียนข้อมูลได้ จึงควรแชร์เฉพาะทีมและเปลี่ยนรหัสหากรั่ว
- กล้องจริงต้องทดสอบบน iPhone Safari และต้องอนุญาตสิทธิ์กล้อง
- Worker ใช้ GitHub Contents API เขียน `products.json` บน `main`; การบันทึกจะสร้าง commit ใน repository
